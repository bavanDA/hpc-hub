Install

HPC Hub is downloaded from its releases page on GitHub. Pick the file for your system, then follow the steps for it.

All downloads are on the releases page of the public bavanDA/hpc-hub repository on GitHub. Each release lists its files under Assets.

The installers are not signed yet, so your system warns you the first time you open the app. The steps below say how to get past that warning. It only happens once.

Linux#

Pick one of these:

  • AppImage, for any distribution. Make it runnable, then start it: 
    chmod +x HPC-Hub_*.AppImage
./HPC-Hub_*.AppImage
  • Ubuntu and Debian: sudo apt install ./HPC-Hub_*_linux_amd64.deb
  • Fedora and RHEL: sudo dnf install ./HPC-Hub_*_linux_x86_64.rpm

For the VPN#

Wulver and Yale need their university VPN. On Linux, HPC Hub uses openconnect for it, and NetworkManager runs the tunnel. Install openconnect from your distribution if you don't have it.

A VPN that signs you in on the university's own web page (Yale's) also needs PyGObject with GTK 4 and WebKitGTK 6:

  • Ubuntu and Debian: python3-gi gir1.2-webkit-6.0
  • Fedora: python3-gobject webkitgtk6.0

Windows 10 and 11#

  1. Download the -setup.exe (or the .msi) and run it. If Windows says Windows protected your PC, click More info, then Run anyway.
  2. Open HPC Hub from the Start menu.
  3. The first time you connect a cluster with a VPN (Wulver, Yale), HPC Hub asks to set up its VPN helper. Click Set up and approve the Windows prompt. This happens once.

macOS#

The macOS build is for Macs with Apple silicon.

  1. Open the .dmg and drag HPC Hub to Applications.
  2. Open it. macOS says it can't check the app. Go to System Settings, Privacy & Security, scroll down and click Open Anyway. This happens once.
  3. The first time you connect a cluster with a VPN, approve Set up the VPN helper and type your Mac password once.

On Windows and macOS, all your DNS goes through the university while the VPN is up. On Windows, Disconnect doesn't sign you out on the VPN server; that session ends by itself.

Android#

The phone app is not on Google Play, F-Droid or any other store yet. Until it is, it is not one of the regular downloads. If an Android file (.apk) is attached to a release, you can install it from there. Otherwise the app can be built from the source code; the steps are in docs/design/android.md in the repository.

Once it is on your phone, the easiest way to sign in is to scan a code from HPC Hub on your computer. See Phone app.
