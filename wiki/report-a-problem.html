Report a problem

HPC Hub can send a problem report for you. You read it before it goes.

Where to find it#

  • Settings, then Report a problem.
  • Report next to an error, on a cluster card, an error message or a page that couldn't load. The report then starts with that error.

Send a report#

  1. Write what you did, what you expected and what happened under What went wrong?
  2. Add your email if you'd like an answer. It is optional and sent as you type it.
  3. Tick Add a screenshot of the window if it helps. Look at it first: its contents are not changed.
  4. Read Everything that will be sent, then select Send report.

The window then says Report sent with a number to use if you write about it later.

What is sent#

Nothing is sent until you select Send. The report holds the app's version, your system, the page, the error, your note, your email if given, and the app's recent log. HPC Hub replaces known sensitive text, such as names, folders, tokens and keys, with placeholders like <user> and <hidden>. Review the report before sending.

Other ways#

You can also open an issue on GitHub. Issues are public, so leave out usernames, group names and paths.
