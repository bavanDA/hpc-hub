AI agents

Run Claude, ChatGPT (Codex), Antigravity or Cursor on a compute node, next to your code and data. They keep working when you close the app, and you decide which commands they may run without asking.

Before you start#

HPC Hub starts the agent's own program on the cluster, so it has to be installed in your account there, and you need your own account with that agent's company. The Ask all window shows Not installed next to any agent it can't find on the cluster.

The four agents are Claude, ChatGPT (Codex), Antigravity and Cursor.

Start an agent#

Open Agents on a cluster card and pick one, or press Open on a project and pick it under Agents. The window, for example Claude on Wulver, has:

  • Task (optional): a first thing to work on, like Fix the failing test in train.py.
  • Folder: where it works.
  • Use a new compute node: off, it shares your node with your terminals; on, it gets a node just for itself. With no node yet, the window asks for the size.
  • Remote control (see below), and the agent's own options, such as Model, Effort, Permission mode or Sandbox.

Press Start. The agent opens in a terminal tab.

Continue a chat#

Under Or continue a chat, the same window lists your earlier chats with that agent on the cluster, newest first, with a search box when there are many. Click one to pick up where you left off.

It keeps running#

An agent runs in a tmux session on a compute node and keeps going when you close the app. The Running tab of the Agents page lists every agent running on your clusters; click one to open it again. Like a terminal on a node, an agent stops when its node's time is up.

Remote control#

Some agents can be used from another device while they run on the cluster:

  • Claude: Remote control lets you use the session from claude.ai/code or the Claude app.
  • ChatGPT: ChatGPT remote lets you use it from the ChatGPT app, one session at a time. A pairing code shows in the terminal; in the ChatGPT app open Codex, connect a machine and enter it.
  • Antigravity: Remote control lets you use it from Antigravity on another device.

Ask all#

Ask all agents, in a project's Open window, puts one question to several agents at once, for example Which of these two plotting scripts is easier to maintain, and why?

  • Prompt, Folder, and Answers go to (a new folder inside the one above, unless you name one).
  • Who answers: switch each agent on or off.
  • Let them read each other's answers: each one answers again after reading the others.

Permissions#

The Permissions tab of Agents sets what Claude may do on a cluster without asking you. It is saved in Claude's own settings on that cluster, so it applies however you start Claude there. Running Claude sessions pick up a change when they restart.

  • Edit files without asking.
  • Move deleted files to the trash: instead of deleting, files go to a trash folder and are kept for 7 days.
  • Ask first: cancelling jobs, force pushing, and throwing away unsaved changes always ask.
  • Run without asking: groups of commands, such as Read and search, Files, Code and builds, Jobs, Git and Network, each with a short note on what it allows. Add a command adds one of your own. Anything not allowed here asks you first.

ChatGPT and Antigravity ask before running commands.

Passcode lock#

The Passcode lock on the same tab guards Claude on a cluster. Once it is set up with Google Authenticator or another authenticator app, Claude takes no messages until you start one with the current code, like 123456 fix the tests. You choose how long a code lasts and how many wrong codes are allowed before it locks; Recent activity shows what happened.

VS Code on a compute node#

VS Code on a cluster card starts VS Code on a compute node as a job of its own, through a VS Code tunnel. When the tunnel is ready the terminal says VS Code is ready with Open in browser. The first time, GitHub asks you to sign in.

VS Code keeps that GitHub sign-in in your home folder on the cluster, unencrypted, so a tunnel on a new node doesn't ask again. Run code tunnel user logout on the cluster if you don't want that.

Experimental tabs#

Skills and Scheduled are two more tabs of Agents. They are experimental and off by default. See Experimental features.
