First sign-in

The first start asks which clusters you use, then walks you through signing in to each one and the size of the compute node you want. After that, connecting is one button.

Pick your clusters#

The first screen is Welcome to HPC Hub, with the question Which clusters do you use? Click each cluster you have an account on, then Continue.

HPC Hub knows Wulver (NJIT), Bouchet (Yale) and Expanse (SDSC). To show or hide one later, open Settings at the bottom of the sidebar and use the switches under Clusters. A hidden cluster keeps its settings.

Sign in to each cluster#

For each cluster you picked there are two short steps: the sign-in, then the compute node. The sign-in is different on each cluster, because each university decides how its people log in. The app shows only what your cluster needs.

Wulver (NJIT)#

Type your UCID and password. When you connect, NJIT asks for a Duo push on your phone.

Yale Bouchet#

Yale uses an SSH key instead of a password. HPC Hub walks you through it:

  1. Make a key: click Create key, or Use a key I already have and pick your private key file.
  2. Send it to Yale: click Copy, then Open key page, paste the key there and click I pasted it. Yale's key page only loads on campus or on the VPN.
  3. Try it. If Yale hasn't picked up the key yet, the app says so. It can take up to 10 minutes.

Yale's VPN has a login of its own, through Yale's Microsoft sign-in page. You can set it under Server and VPN in Yale's settings (see below).

SDSC Expanse#

Expanse uses your ACCESS username. You have two ways in:

  • Sign in with the portal, which is the recommended way. No password is stored.
  • Your username and password, plus a code from your authenticator app at every sign-in. Set up your authenticator app shows how to get one.

Remember password#

With Remember password on, the password is kept on this computer in the system keyring (see where passwords are kept). Turn it off and you'll type it each time you open HPC Hub.

If you are not ready, Do this later skips the step. You'll be asked when you connect.

Choose a compute node size#

The second step is Compute node on Wulver (or your cluster). Your terminals and agents run on a compute node, not on the busy login node.

  • Get a compute node when I connect: on, and a node is ready as soon as you sign in. Off, and you can still get one from the cluster card.
  • The size: Cores, Memory, Time, and Queue and priority. The app checks these against what the cluster allows. See Compute nodes and queues.
  • Ask before each request: shows the node window each time you connect, so you can change the size first.

Press Continue (or Done on the last cluster) and you land on the Clusters page.

Connecting#

Each cluster has a card on the Clusters page. Press Connect. The card shows each step as it happens, and a short log under it:

  1. VPN, for clusters behind one (Wulver, Yale). On Windows and macOS, the first time, you are asked to set up the VPN helper.
  2. Sign-in with your saved login. A sign-in page that needs you (a university web login) opens in a window of the app.
  3. Duo, where the cluster uses it: Approve Duo on your phone, with a timer. If nothing happens, the app says No answer from Duo yet. Pushes expire after about a minute. and offers Send a new push.
  4. The compute node, if you asked for one: Waiting for a free node. Usually under a minute, longer when the cluster is busy.

Once connected, the card shows your node and buttons for Terminal, VS Code, Files and Agents. Stop signing in or Stop waiting cancels at any point. If something fails, the card says what went wrong in a sentence and the button turns into Try again.

One VPN at a time#

On a computer, only one university VPN can run at a time. If you connect Yale while Wulver is up, HPC Hub asks first: Only one VPN can run at a time. Wulver disconnects and its node is released. The phone app doesn't have this limit.

VPN only#

The ⋮ menu on a card has Connect VPN only, for when you need the university network but not the cluster (for example, to open Yale's key page).

Change a saved login later#

Click the gear on a cluster card (Wulver settings, for example). It has:

  • Sign-in: your username, and Forget password to remove the saved one. You'll type it next time you connect.
  • Authenticator app, on clusters that ask for a code.
  • Compute node: the size to ask for, and whether to get one when you connect.
  • Under Advanced: Server and VPN (the login host, the VPN gateway, a separate VPN login), VS Code job and Agents. Changes apply the next time you connect.

Your saved VPN password is only typed into the sign-in pages of your university's own site or a known sign-in provider, over https.
