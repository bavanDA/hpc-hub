Experimental features Experimental

Three parts of HPC Hub are still taking shape. They are off by default, and each has its own switch.

Turn them on in Settings, under Experimental. As the app says there, they may change or break.

Papers (LaTeX)#

The Papers switch adds a Papers page to the sidebar: an editor for LaTeX papers that live in a project on the cluster, with builds done there.

  • Views: Editor, Both (source and PDF side by side), PDF and Reader.
  • Builds with latexmk, and jumps between a line of source and its place in the PDF.
  • Git: commit, pull and push.
  • History: a timeline of the paper's changes, comparing versions, who last changed each line and why, and notes. Notes are kept next to the paper in .git, and are never committed or pushed.
  • Assist: Ask about asks the agent about the selected text or a line, and the agent can write commit messages and compare your open notes with your changes. You decide each one.

With Papers on, Settings also has Agent for papers, the agent used for this. It runs on your compute node. A new project can start as a LaTeX paper.

Skills#

The Skills switch adds a Skills tab to Agents: what each agent knows on a cluster. Add skills to the agents on each cluster, from HPC Hub's own set or from any git repository.

Scheduled agents#

The Scheduled agents switch adds a Scheduled tab to Agents: an agent runs a task on its own at set times, for example every night at 02:00. Each run is a Slurm job on the cluster, so it runs with your laptop off and is billed like any other job. Each run keeps a log you can read.
