Files, transfers and Globus

Browse your folders on every cluster, preview and edit files, upload and download, and copy between clusters through your laptop or with Globus.

Browse#

The Browse tab of Files shows one cluster at a time. On the left are your places (home and the cluster's other storage); at the top, the path, which you can type into. Click a file to preview it: PDFs, images and text show next to the list.

Right-click a file or folder (or use its menu) for:

  • Open, and Edit in Code for text files.
  • Download, Rename, Copy path.
  • Make a zip, or Extract here for an archive. Both run on the cluster.
  • Copy, then paste on any cluster.
  • Delete, which asks first. It deletes for good on the cluster; there is no trash.

Right-click empty space for New folder, Upload files here, Paste here, Open this folder in Code and Copy path.

The PDF viewer can search the text, zoom, look words up in a dictionary and read the text aloud.

Copy between clusters#

  1. Choose Copy, then paste on any cluster on a file or folder.
  2. Go to the other cluster and the folder you want, and choose Paste here.
  3. Pick How:
    • Through this laptop: keep HPC Hub open and this computer awake until it is done. Simple, fine for smaller copies.
    • Globus: cluster to cluster, keeps going with the app closed. Much faster for big folders.

Both clusters have to be connected. The app measures the size first, and tells you when a copy is done.

Transfers#

The Transfers tab lists copies through this laptop at the top, with Globus below it: two panes, one per cluster, and Recent transfers with progress. Select something in one pane and send it to the other. Cancel transfer and Open in Globus are on each transfer.

Set up Globus#

Globus moves big folders between clusters on its own, even with the app closed. It needs a one-time setup.

  1. Make a free Globus app id. At app.globus.org go to Settings, Developers, and register an app. Choose the one for native applications that are distributed to users, name it HPC Hub, and add the redirect https://auth.globus.org/v2/web/auth-code. Paste its Client ID under Set up Globus and press Save.
  2. Sign in to Globus with your university login. It opens in your browser. If Globus shows a code, paste it back into the app.
  3. Collections. HPC Hub finds each cluster's Globus collection by itself. If it can't, pick it from the list.
  4. Permissions. When a collection needs your OK, the app shows Globus needs your permission. Press Allow; it asks only for what Globus needs.

On some clusters your Globus collection only works while Globus Connect runs there. If it isn't running, the app says so and offers to start it on the login node.
